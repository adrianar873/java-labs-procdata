# Java Labs - Proyectos Variados

Repositorio con varios ejercicios de Java, incluyendo acceso a MongoDB, manejo de datos JSON y procesamiento paralelo.

## Estructura de Carpetas

### `exOrm`
Ejercicio de ORM y manejo de datos meteorológicos.  
- **MongoConnection.java**: Singleton para la conexión a MongoDB.  
- **WeatherDao.java**: DAO para CRUD de objetos `Weather`.  
- **WeatherApp.java**: Ejemplos de inserción, consulta, actualización y borrado de datos meteorológicos.

### `paralelizarJson`
Procesamiento paralelo de archivos JSON.  
- Lectura y transformación de datos en memoria.  
- Ejecución de tareas concurrentes para optimizar el rendimiento.

### `HiloCalcularMatrix`
Paralelización de operaciones con matrices.  
- Multiplicación de una matriz por otra.  
- Multiplicación de una matriz por un escalar.

### `mongodb`
Ejercicios básicos de introducción a MongoDB.  
- Configuración de conexión y operaciones simples.
